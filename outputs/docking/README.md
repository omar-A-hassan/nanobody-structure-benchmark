# 7R73 Docking and Epitope-Recovery Results

This directory contains the derived results from the illustrative 7R73 D7 VHH–HIV-1 gp120 docking case.

## Files

- `7R73_top1_docking_epitope.csv` — supplied top-1 HDOCK/DockQ and epitope summary.
- `7R73_best_top10_docking_epitope.csv` — supplied best-DockQ summary among the ten ranked candidates per input.
- `7R73_prepared_regional_rmsd.csv` — computed H1/H2/H3/framework RMSDs for the four supplied prepared monomers.
- `7R73_prepared_regional_rmsd.json` — matching scores, reference/source hashes, atom counts and independent alignment checks.

The regional files are generated by `src/score_prepared_vhh.py`. Run it with
`--check` to verify the saved values without replacing them. The supplied
docking summary CSVs are preserved unchanged; retained pose files and their
DockQ/epitope/table-generation procedure are not included in this update.

The docking analysis is a single illustrative case and should not be interpreted as establishing a general relationship between regional VHH prediction error and docking performance.
