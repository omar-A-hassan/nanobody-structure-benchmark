# 7R73 Docking and Epitope-Recovery Results

This directory contains the derived results from the illustrative 7R73 D7 VHH–HIV-1 gp120 docking case.

## Files

- `top1_docking_results.csv` — Top-1 HDOCK pose quality and epitope-recovery results for the experimental, NanoBodyBuilder2, IgFold, and SimpleFold VHH inputs.
- `best_top10_results.csv` — Best-DockQ pose among the Top-10 HDOCK candidates for each VHH input.
- `epitope_recovery.csv` — Epitope-recovery metrics for the retained docking poses.
- `poses/` — retained HDOCK pose files, if archived.

The docking analysis is a single illustrative case and should not be interpreted as establishing a general relationship between regional VHH prediction error and docking performance.
